# MedMinder

MedMinder is an Android medication-management application that helps users organise medicines and medication schedules.

## Sprint 1 Completed

- Created the Android Studio project
- Added biometric Secure Access screen
- Added empty Medication Dashboard
- Added Add/Edit Medication navigation placeholder
- Added My History navigation placeholder
- Added working back navigation
- Tested the application on an Android emulator

- Android Studio
- Kotlin
- Jetpack Compose
- Navigation Compose
